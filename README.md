# Сэдэв №14. Hallucination: хэлний загвар яагаад итгэлтэйгээр худал ярьдаг вэ

## Багийн гишүүд:
- Гишүүн 1 (Зохицуулагч): Б.Сарангэрэл
- Гишүүн 2 (Судалгаа хариуцагч): Г.Даваасүрэн
- Гишүүн 3 (Анализ хариуцагч): М.Зулаа
- Гишүүн 4 (Бичиг баримт ба Илтгэл хариуцагч): Б.Гурван-Эрдэнэ

## Төслийн зорилго:
Хэлний загварын гаргаж буй худал мэдээлэл (hallucination)-ийн шалтгаан, магадлалын үндсэн зарчмыг судалж, бодит жишээ цуглуулан шинжилгээ хийх.
